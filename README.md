# ChainTeams 组队锁链（PEAK）

原版"链在一起(Chained)"的升级版：不再把全房间串成一条链，而是**由房主自由分组，每组一条独立的锁链**。

- **自由分组**：最多 **6 组**（红/蓝/绿/黄/紫/青），组可添加/删除/改名；每组最多 **6 人**（配置可调小）
- 分组由**房主**通过游戏内界面（默认 **F9**）完成，实时同步给所有玩家
- **组内排序**：组员行只有 上移 / 下移 / 移除 三个操作，上=靠近链头；加入分组从"未分组"区点 `+组名`
- **参数入面板（设置页）**：面板分「分组管理」「设置」两页；设置页有 链长 / 拉扯强度 / 最大拉力 三条滑条 + 恢复默认，拖动即时生效并同步全房间（拖动中每 0.5 秒同步一次）
- **面板仅房主可开**：联机进房后（含机场大厅）只有房主能按热键打开，成员与主菜单按热键均无反应；房主迁移后新房主自动获得面板，左上角 HUD 对所有玩家可见
- 面板默认占屏幕约 1/2（配置 `General.PanelSize` 30–95 可调，改后重开面板生效），带硬上限永不出屏
- **皮肤色渐变锁链**：每段锁链的颜色在两端角色的皮肤颜色之间过渡（取自外观系统的皮肤调色板）
- 组内玩家互相锁链拉扯（距离超过链长才开始拉，参数可调），组与组互不影响
- 未分组的玩家不参与锁链；跳组按钮 `→红组` 一键换组（接目标组链尾）
- 玩家掉线自动从组里移除；房主迁移后新房主自动获得分组权限
- 后加入的玩家自动收到当前分组状态（含链内顺序）

## 安装

1. **删除旧版 Chained mod**（`BepInEx/plugins/com.github.Quaree.Chained(2).dll`），两套锁链会同时拉扯。
2. 把 `ChainTeams.dll` 放进 `BepInEx/plugins/`。
3. **房间里所有玩家都要装**，锁链物理是每个玩家在自己客户端对自己施力，没装的人不会参与拉扯（但分组状态仍会同步）。
4. 超过 4 人的房间需配合 PEAKUnlimited 等人数解锁 mod。

## 使用

1. 按 **F9** 打开面板（任何场景都有效：未联机时会显示提示而不是无反应；默认键位可在 `BepInEx/config/com.peakmod.chainteams.cfg` 改）。
2. 房主点"**○ 已停用（点击启用）**"开启锁链系统。
3. 在「未分组」区给每人点 [+红组] / [+蓝组] / [+绿组]；组满后按钮自动禁用；组内行有 [→其他组] 和 [解除]。
4. 拖动组内的 `≡` 柄调整链内顺序（上 = 靠近链头），插入位置会显示组色指示线，松开鼠标生效。
5. 也可以用"**智能分组**"按进场顺序一键均分。
6. 成员端打开面板可实时查看分组与顺序（只读）。

## 配置（BepInEx/config/com.peakmod.chainteams.cfg）

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| General.UIHotkey | F9 | 分组面板开关键 |
| General.PanelSize | 66 | 面板占屏幕的百分比（宽高同比例，30–95，改后重开面板生效） |
| General.MaxPerTeam | 6 | 每组人数上限（≤6，房主端生效） |
| General.MaxGroups | 6 | 组数上限（≤6，房主端生效） |
| Physics.ChainLength | 5 | 锁链自然长度默认值（进房后以房主 UI 设置为准） |
| Physics.PullStrength | 25 | 拉扯强度默认值 |
| Physics.MaxPullForce | 350 | 单次拉扯最大力度默认值 |
| Visual.ChainWidth | 0.09 | 锁链粗细 |
| Visual.ShowChains | true | 是否绘制锁链 |

## 已知边界

- 玩家**退出重进**会拿到新的玩家编号，原分组条目失效，房主需重新分组（面板上有红字提示旧 mod 冲突时会显示）。
- 观战/死亡中的玩家暂时脱离锁链，复活自动回到原组与原位置。
- 机器人不参与锁链。
- 皮肤色取自外观系统的调色板；穿相同皮肤的角色之间那段线是纯色（两端同色，视觉上无渐变）。

```
powershell -ExecutionPolicy Bypass -File build.ps1        # 编译并部署到 BepInEx/plugins
powershell -ExecutionPolicy Bypass -File build.ps1 -Package  # 另外打包 zip
```

## 排障记录（2026-10-28）

症状：从 Steam 启动游戏后所有 mod 集体失效（F9 等热键全部无反应），直接启动 PEAK.exe 则一切正常。
根因：Steam.exe 进程环境里被注入了 `DOORSTOP_DISABLE=TRUE`，它启动的所有游戏都继承该变量，doorstop 因此跳过 BepInEx 注入。
修复：重启 Steam（干净环境启动）即恢复。已顺带把 doorstop_config.ini 的 ignore_disable_switch 设为 true（该版本 doorstop 实测不生效，留着无害）。
快速自检：游戏跑起来后看 `C:\Users\<用户>\AppData\Local\LandCrab\PEAK\TrueFinalAscent\Logs\` 有没有新会话目录——没有就是 mod 没加载，先重启 Steam。
